## Proyectos destacados

### [Scouting360](https://github.com/Iker-MR/scouting360)
API REST para crear y consultar perfiles de futbolistas, con posición, atributos, búsqueda y filtros.

- Autenticación JWT con el token de refresco en cookie `httpOnly`, rotación y lista negra al cerrar sesión.
- Permisos por propietario y control de perfiles duplicados en peticiones simultáneas.
- 56 tests automatizados.

`Python` `Django` `Django REST Framework` `SimpleJWT` `SQLite`

### [Simulador de inversión](https://github.com/Iker-MR/Simulador-de-inversion)
Dashboard que calcula la evolución de una inversión con interés compuesto, la muestra en gráficas y exporta los datos a CSV.

- Lógica de cálculo y formato separada de la interfaz.
- 14 tests con pytest.

`Python` `Streamlit` `Pandas` `Plotly` `pytest`

### [IA desde cero](https://github.com/Iker-MR/ia-desde-cero)
Mi recorrido por el curso abierto *AI Engineering from Scratch*, con el código y las notas de cada lección.

- Motor de autodiferenciación propio con el que entreno una red neuronal que aprende XOR. Sus gradientes coinciden con los de PyTorch en las pruebas de la lección.
- Filtro de spam Naive Bayes y comparación de optimizadores: Adam resuelve la función de Rosenbrock en 767 pasos, frente a 18.599 del descenso de gradiente normal.

`Python` `NumPy` `PyTorch` `API de Claude`
